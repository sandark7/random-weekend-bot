# Agent Notes

Before starting a new implementation change, read the consolidated specs in
`openspec/specs/` and any active change under `openspec/changes/`.

For feature work, keep the OpenSpec flow:

1. Proposal: intent, scope, success criteria.
2. Delta specs: behavior-first requirements and scenarios.
3. Design: technical approach and trade-offs.
4. Tasks: small implementation checklist, updated as work progresses.
5. Implementation: code and tests follow the accepted artifacts.
6. Archive: completed changes are merged into `openspec/specs/`.
